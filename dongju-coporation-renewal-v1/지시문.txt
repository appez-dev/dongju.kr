3. 각 메뉴별 콘텐츠 구성 및 무료 이미지/SVG 활용 방안
첨부하신 캡처 파일과 회사소개서 텍스트를 바탕으로 각 페이지의 구성안을 정리

A. 회사소개
*CEO 인사말: www.dongju.kr_CES 인사말.jpg 파일의 내용을 텍스트화하여 배치. "기업의 핵심 자산인 데이터를 안전하게 보호..."라는 핵심 메시지를 큰 타이틀로 뽑아 시선을 유도. 
└이미지 제안: 제공된 최선인 대표님의 사진을 우측에 배치하고, 배경에는 추상적인 데이터 흐름을 나타내는 은은한 무료 이미지(Unsplash의 Abstract Network 등)를 합성.
└SVG 제안: 인사말 상단에 큰 따옴표(") 모양의 깔끔한 SVG 아이콘을 사용하여 메시지를 강조

└SVG 제안: 각 가치별로 직관적인 SVG 라인 아이콘(예: 방패, 톱니바퀴, 상승 그래프 등)을 매칭.

*레퍼런스: 회사소개서에 명시된 SK텔레콤, 미코, 한국토지주택공사, 삼성중공업 등 70여 개 이상의 주요 고객사 목록을 활용.
└이미지 제안: 고객사 로고들을 무채색(Grayscale)으로 변환한 뒤, 롤링 배너(Carousel) 형태로 흘러가게 배치.

B. 사업분야 (Solutions)
*Dell Technologies: www.dongju.kr_솔루션_Dell.jpg의 내용을 활용하여 데이터 백업(NetWorker, Avamar), 스토리지(UnityXT, PowerStore), HCI(VxRail) 등 카테고리를 탭(Tab) 메뉴로 나누어 구성.
└이미지 제안: 현대적인 데이터센터 서버룸 무료 고화질 이미지를 상단 헤더 배경으로 사용.

*ABLESTACK (HCI): www.dongju.kr_솔루션_HCI.jpg의 핵심 문구인 "VM웨어 영구 라이선스 종료 및 구독형 전환 부담되는 IT 인프라 비용 완벽 대체"를 헤드라인으로 사용.
└SVG 제안: 기존 환경에서 ABLESTACK으로 넘어가는 과정을 보여주는 마이그레이션(화살표 및 서버) SVG 아이콘을 중간에 삽입.

*MDR: www.dongju.kr_솔루션_MDR.jpg에 포함된 PAGO DeepACT Endpoint with SentinelOne의 주요 특징(랜섬웨어 대응, 롤백 기능)을 블록 형태로 구성.
└이미지 제안: 짙은 네이비 톤의 사이버 보안, 디지털 자물쇠(Cyber Security Lock) 관련 무료 이미지를 활용.

C. 고객문의(Contact Us)
이름, 연락처, 이메일, 문의 분류(도입 문의, 유지보수 문의 등), 내용 입력란 및 개인정보처리방침 동의 체크박스로만 심플하게 구성. 향후 외부 API 서비스(Formspree 등)를 연동.


## 산출물 요구사항
0. 모든 응답 및 요청은 한글로 해줘.
1. 작업 폴더를 생성(이름은 추천해줘)해서 해당 폴더에서 작업 해줘.
2. 이미지 경로는 대체 텍스트(Alt)나 미니멀한 SVG 플레이스홀더, 혹은 Unsplash의 비즈니스 이미지 링크를 활용해줘.
3. Git은 사용하지 않을꺼야. 버전관리는 필요에 따라 내가 진행할께.
4. 모든 작업은 오직 PowerShell 스크립트만을 사용하여 자동화 코드로 실행해줘.
5. 파일 저장 시 인코딩 형식인 UTF-8 BOM이 유실되거나 다국어 문자가 깨지지 않도록 파일 I/O 처리에 각별히 유의해줘.
